Featured project · Self-hosted cloud drive

Single File Flask Drive

A directly deployable, single-file Flask cloud drive. The backend routes, SQLite metadata logic, embedded HTML templates, CSS, and JavaScript are all contained in app.py, without a separate frontend project or build step.

  • Supports account management, hierarchical folders, uploads, downloads, renaming, deletion, drag-and-drop movement, and breadcrumb navigation.
  • Provides file and folder sharing, in-browser audio/video playback, online plain-text editing, and read-only viewing from shared pages.
  • Metadata is stored in SQLite while file contents remain on disk. Folder downloads are generated as temporary .7z archives to reduce memory pressure when packaging large directories.

Network programming · Encrypted proxy

AegisRoute

A lightweight two-file Python proxy tunnel composed of an interactive client and server. The client exposes local HTTP, HTTPS CONNECT, SOCKS5 TCP, and SOCKS5 UDP endpoints, with TCP and UDP forwarded through their corresponding encrypted transport paths. The tunnel uses a shared password, HKDF-SHA256, and ChaCha20-Poly1305 to protect data and does not decrypt HTTPS traffic.

Desktop tool · Password security

CipherNoteVault

An offline password manager and secure-notes application built with Python and PyQt6. The master password is processed with Argon2id to derive a 256-bit key, and the entire .cnvault payload is authenticated and encrypted with ChaCha20-Poly1305. The database stores no master password, plaintext passwords, plaintext notes, or recovery backdoor, and the application includes password generation, search, and timed clipboard clearing.

Secure communication · Multiplexing

XFM4 SecureMux

A bidirectional encrypted communication tool in Python that transfers real-time text messages and multiple large files over one TCP connection. It uses ephemeral X25519 keys, direction-specific keys derived with HKDF-SHA256, and ChaCha20-Poly1305. Logical-stream multiplexing, chunked I/O, priority scheduling, bounded queues, and multithreading preserve responsiveness, while completed files are checked for received size and SHA-256 digest.

PythonX25519TCPMultiplexing

Rust · Asynchronous proxy

rproxy

A lightweight local proxy server written in Rust with Tokio, providing HTTP, HTTPS CONNECT, SOCKS5 CONNECT, and SOCKS5 UDP ASSOCIATE modes. It listens on both IPv4 and IPv6 loopback addresses by default and uses asynchronous concurrent networking, TCP keepalive, and local runtime logging. HTTPS mode only forwards byte streams through CONNECT tunnels and performs no TLS decryption or man-in-the-middle inspection.
