重点项目 · 自托管云盘

Single File Flask Drive

一个可直接部署的单文件 Flask 自托管云盘。完整后端路由、SQLite 元数据逻辑、内嵌 HTML 模板、CSS 与 JavaScript 均集中在 app.py 中，无需独立前端工程或构建步骤。

  • 支持账户管理、层级文件夹、上传下载、重命名、删除、拖拽移动和面包屑导航。
  • 提供文件与文件夹分享、在线音视频播放、纯文本在线编辑及共享页面只读查看。
  • 元数据存入 SQLite，文件内容保存在磁盘；文件夹下载通过临时 .7z 归档生成，减少大目录打包时的内存压力。

网络编程 · 加密代理

AegisRoute

轻量级双文件 Python 代理隧道，由交互式客户端与服务端组成。客户端提供本地 HTTP、HTTPS CONNECT、SOCKS5 TCP 和 SOCKS5 UDP 入口，TCP 与 UDP 分别通过对应的加密传输路径转发；隧道使用共享密码、HKDF-SHA256 与 ChaCha20-Poly1305 保护数据，不解密 HTTPS 内容。

PythonTCP/UDPSOCKS5ChaCha20-Poly1305

桌面工具 · 密码安全

CipherNoteVault

使用 Python 与 PyQt6 构建的离线密码管理器和安全笔记应用。主密码经 Argon2id 派生 256 位密钥，整个 .cnvault 数据载荷由 ChaCha20-Poly1305 认证加密；数据库不保存主密码、明文密码、明文笔记或恢复后门，并提供密码生成、搜索及剪贴板定时清除等功能。

Face Search Tools

安全通信 · 多路复用

XFM4 SecureMux

Python 双向加密通信工具，可在单个 TCP 连接中同时传输实时文本消息和多个大文件。项目使用临时 X25519 密钥、HKDF-SHA256 双向派生密钥和 ChaCha20-Poly1305，并通过逻辑流多路复用、分块 I/O、优先级调度、有界队列与多线程保持交互响应；文件完成后校验接收大小和 SHA-256 摘要。

Rust · 高性能代理

rproxy

使用 Rust 与 Tokio 编写的本地轻量代理服务器，提供 HTTP、HTTPS CONNECT、SOCKS5 CONNECT 和 SOCKS5 UDP ASSOCIATE 四种代理模式。程序默认同时监听 IPv4 与 IPv6 回环地址，采用异步并发网络处理、TCP keepalive 和本地运行日志；HTTPS 模式仅转发 CONNECT 隧道中的字节流，不进行 TLS 解密或中间人检查。
